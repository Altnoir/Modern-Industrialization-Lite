# The Processing Table

Machines are not built directly on a crafting table. They are assembled on the **Processing Table**, a simple bench on which you combine a machine casing with the one part that gives the machine its purpose.

<Recipe id="milite:processing_table/processing_table" />

First craft a machine casing, then place it in one of the two input slots together with the characterising item of the machine you want. The order of the two slots does not matter.

<Recipe id="milite:steam_age/bronze/machine_casing_asbl" />

For example, a **bronze machine casing** and a **furnace** make a bronze boiler. The same casing with a **copper gear** makes a compressor, with a **diamond** a macerator, and so on. Each machine's page in this book shows its exact recipe.

Steel machines work exactly the same way: use a **steel machine casing** instead of a bronze one.
